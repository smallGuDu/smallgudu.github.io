# 歌曲 歌手 操作
使用说明
  1. 在网易云音乐里打开歌单 → 分享 → 复制链接，粘贴到上面即可（会自动识别歌单 ID）。
  2. 「打包 ZIP 下载」生成一个压缩包，只弹一次保存框，适合整张歌单；「分别下载」会逐首触发保存，浏览器可能询问是否允许下载多个文件。
  3. 音质选「无损 FLAC」时，仅当该歌曲有 FLAC 版本才有效，否则会自动回落到 MP3。
  4. 解析与下载都在你的浏览器里完成，不经由本站服务器存储。请支持正版音乐，下载内容仅限个人试听使用。
